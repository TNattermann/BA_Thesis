## About the Thesis

- **Title:** Analyzing and predicting user behavior in online marketing
- **Author:** Torben Nattermann
- **Degree Program:** B.Sc. Data Science
- **Institution:** Hochschule Karlsruhe – University of Applied Sciences (HKA)
- **Industry Partner:** DefineMedia GmbH
- **Duration:** November 2023 – February 2024

This bachelor thesis was conducted in cooperation with **DefineMedia GmbH**, addressing a project on emotion classification. The work covers the full pipeline from data preparation and model development to evaluation of results, as documented in the accompanying manuscript.
